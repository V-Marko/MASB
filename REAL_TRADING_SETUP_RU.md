# MASB — REAL Binance USDⓈ-M Futures (fibZZ10 only)

## Текущие защитные ограничения

- Реальное исполнение разрешено только стратегии `fibZZ10`.
- Остальные стратегии продолжают работать через прежний DEMO/виртуальный контур.
- REAL выключен по умолчанию: `MASB_REAL_TRADING_ENABLED=false`.
- Глобальный лимит — максимум 2 занятых символа (открытые позиции и ожидающие входы MASB).
- На одном символе допускается только одна позиция/ожидающий вход.
- Поддерживается только Binance USDⓈ-M Futures в режиме One-way. При Hedge Mode исполнение блокируется.
- Плечо выставляется максимум в 5x; тип маржи автоматически не меняется.
- Рабочий капитал ограничен `MASB_REAL_CAPITAL_USDT=100` USDT (если доступный баланс ниже — используется он).
- Риск рассчитывается как 1% рабочего капитала с оценкой комиссии входа и выхода по 0.055% на сторону.
- Номинал суммарно ограничен рабочим капиталом × 5.
- В REAL отправляется только первый вход fibZZ10 на символ. Второй Fibonacci-вход остаётся в сигнале/DEMO, потому что усреднение одной One-way позиции потребовало бы отдельной логики пересчёта среднего Entry и защитных заявок.
- Вход — LIMIT GTC; SL и TP — биржевые conditional algo orders с `closePosition=true` и `workingType=MARK_PRICE`.
- При ошибке создания защитных заявок код пытается отменить вход и уже созданный SL.

## Настройка

1. Установить зависимости: `pip install -r requirements.txt`.
2. Скопировать `.env.example` в `.env`.
3. Заполнить `TELEGRAM_BOT_TOKEN`, `BINANCE_API_KEY`, `BINANCE_API_SECRET` локально на компьютере владельца Binance-аккаунта.
4. Для первого запуска оставить `MASB_REAL_TRADING_ENABLED=false`.
5. API-ключ должен иметь только необходимые права чтения и USDⓈ-M Futures trading. Вывод средств должен быть запрещён; по возможности включить IP whitelist.
6. Проверить, что аккаунт находится в One-way Mode. Бот не переключает режим автоматически.
7. Не отправлять `.env`, API key или secret в Telegram, GitHub, архивы и этот чат.

## Включение REAL

Только после самостоятельной проверки владельцем аккаунта, успешного DEMO-прогона и проверки минимальных лотов/шагов конкретных символов можно вручную изменить локально:

`MASB_REAL_TRADING_ENABLED=true`

Это включает реальные заявки. Не включать на аккаунте с незнакомыми открытыми позициями или ордерами: глобальный лимит учитывает все открытые Futures-позиции консервативно.

## Важные ограничения

- API-ответы Binance, фильтры, минимальные номиналы и доступность Futures для конкретного аккаунта могут отличаться.
- Рыночные гэпы, проскальзывание, частичное исполнение и комиссии могут привести к фактическому убытку выше расчётного 1 USDT. Стоп-маркет не гарантирует цену исполнения.
- Реальные позиции, открытые вручную или другим ботом, также учитываются в глобальном лимите; бот не должен ими управлять.
- После закрытия позиции синхронизатор отменяет остаток входного ордера и защитные algo-заявки. Синхронизация выполняется периодически, а не мгновенно.
- Не использовать этот код как гарантию сохранности капитала или доходности. Проверить на минимально допустимом размере и под наблюдением владельца аккаунта.
