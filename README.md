# MASB — My All Strategy Bot

Начальная основа проекта для Windows 11. На этом этапе подключено Telegram-меню для просмотра состояния и настроек. Торговые сигналы, рыночные данные, backtest и реализация четырёх стратегий пока отсутствуют.

## Требования

- Python 3.11 или новее
- Windows 11

## Установка и запуск (PowerShell)

```powershell
cd path\to\MASB
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
python main.py
```

Создайте `.env` из `.env.example` и вставьте токен Telegram от @BotFather. Запустите `python main.py`; при пустом `TELEGRAM_CHAT_ID` бот покажет ID личного чата. Добавьте ID в `.env`, перезапустите MASB. Управление доступно только из этого личного чата. Не вставляйте токены в Git.

## Telegram-меню

Команды: `/start`, `/status`, `/balance`, `/strategies`, `/help`. Кнопки меню дублируют эти просмотры. До настройки `TELEGRAM_CHAT_ID` доступен только шаг получения собственного chat ID; остальные команды заблокированы. Telegram-бот не размещает реальные ордера.

## JSON-хранилище

Рабочие JSON-файлы создаются автоматически в `data/` при первом запуске и игнорируются Git. `core/json_storage.py` поддерживает UTF-8, атомарную замену, блокировки потоков/процессов, резервные копии важных документов и сохранение повреждённых файлов для диагностики. Денежные значения следует хранить строками, например `"12.3400"`, и преобразовывать в `Decimal` в торговой логике.

Если повреждён JSON, загрузка не сбрасывает состояние молча: повреждённый файл переименовывается в файл с суффиксом `.corrupt_...`, а вызывающий код получает ошибку. Если доступна исправная `.bak`, данные восстанавливаются из неё, но также выдаётся диагностическая ошибка, чтобы оператор обратил внимание на инцидент.

## Безопасность GitHub

- `.env` и рабочие JSON игнорируются.
- В Git допустим `.env.example` только с безопасными заглушками.
- `data_templates/config.example.json` — безопасный пример, не рабочее состояние.
- Не публикуйте журналы, реальные API-ключи, Telegram-токены или личные данные.

## План разработки

Реализовывать по одной задаче за раз. Сначала тестируется инфраструктура хранения; торговая логика не добавляется, пока правила четырёх стратегий не подтверждены пользователем.


## REAL Binance Futures (fibZZ10 only)

Подготовлен отдельный модуль `services/binance_futures.py`. Реальное исполнение по умолчанию выключено (`MASB_REAL_TRADING_ENABLED=false`) и допускается только для `fibZZ10`; остальные стратегии продолжают работать в DEMO. Инструкция по локальной настройке, ограничениям и рискам находится в [`REAL_TRADING_SETUP_RU.md`](REAL_TRADING_SETUP_RU.md). Используй `.env.example` как шаблон и не передавай `.env`/API-секреты.


## REAL / DEMO для стратегий

В Telegram откройте **🧩 Стратегии → нужная стратегия** и используйте кнопку **🧪 DEMO / 🔴 REAL**. Новые и существующие стратегии после обновления остаются DEMO, пока владелец явно не включит REAL. Глобальный переключатель `.env` `MASB_REAL_TRADING_ENABLED` остаётся дополнительной защитой.
