MASB — исходный проект (обновлённая ZIP-сборка)

1. Распакуй ZIP в отдельную папку.
2. Установи Python 3.11 или 3.12 с python.org (при установке включи Add Python to PATH).
3. Скопируй .env.example в файл .env.
4. Открой .env и замени PASTE_YOUR_TELEGRAM_BOT_TOKEN_HERE на токен от BotFather.
5. Запусти start.bat.

Новая стратегия:
- Имя в MASB: obHunter
- Таймфрейм: 1h
- Order Block + Liquidity Sweep + BOS + фильтр EMA 50/200 + ATR
- Риск расчёта: 3% виртуального капитала на сделку
- Risk/Reward: 1:3
- Максимальное плечо для расчёта размера позиции: 5x
- Комиссия указана в метаданных: 0.055% на сторону
- Используются виртуальные сделки; реальные ордера на биржу не отправляются.

Важно:
- В архив намеренно не включён .env, так как он может содержать секретный Telegram-токен.
- В архив не включены .venv, .git, логи и пользовательские runtime-файлы JSON.
- Стратегия появится в меню MASB автоматически при запуске, так как проект сканирует strategy/*.py.
- Наличие сигнала не гарантируется на каждом сканировании. Торговые стратегии не гарантируют прибыль.
